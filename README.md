# US Momentum Research

Python 기반 미국 주식 급등주 데이터 수집·분석 연구 프로젝트의 포트폴리오입니다.

**현재 연구·개발 단계입니다.** 데이터 수집과 관측 이후 가격 흐름의 분석을 다루며, 수익성이 검증된 매매 시스템이나 완성된 서비스로 소개하지 않습니다.

## 프로젝트의 목적

급격한 가격 변동이 발생한 종목의 데이터를 수집하고, 관측 시점과 이후 가격을 연결해 분석할 수 있는 연구 환경을 구축하고 있습니다. 가격 변화뿐 아니라 누락, 관측 지연, 중복 같은 데이터 품질 문제도 함께 다룹니다.

## 원본 프로젝트에서 확인한 구성

소스 검토 기준으로 다음 구성 요소를 확인했습니다. 이 공개 저장소에서 전체 수집기를 실행할 수 있는 것은 아닙니다.

```mermaid
flowchart LR
    A[후보 종목 탐색] --> B[시세·분봉 수집]
    B --> C[특징값과 관측 시점 기록]
    C --> D[관측 이후 가격 추적]
    D --> E[연구 데이터셋 생성]
    E --> F[데이터 품질 점검·분석]
```

- REST API 인증과 시세 조회, WebSocket 관련 코드
- 종목 필터링과 특징값 기록
- 관측 이후 가격 수집 및 연구 데이터셋 생성
- 요청 간격과 작업 시간 예산을 관리하는 수집 코드
- 수집·분석 동작을 확인하기 위한 테스트 코드

원본의 주요 사용 기술은 Python, pandas, requests, websocket-client 등입니다. 위 목록은 구현 구성에 대한 설명이며 실거래 성과나 운영 안정성의 검증 결과가 아닙니다.

## 이 저장소에서 실행할 수 있는 것

민감한 원본 코드와 분리해 새로 작성한 **오프라인 데이터 품질 점검 예제**를 제공합니다. 합성 데이터에서 중복 관측을 제거하고, 누락되거나 유효하지 않은 가격을 구분한 뒤 관측 전후 가격 변화율을 요약합니다.

- 예제의 종목명·시간·가격은 모두 설명을 위해 만든 합성 값입니다.
- 원본 수집 데이터의 발췌나 익명화 자료가 아닙니다.
- 예제 코드는 포트폴리오 정리 과정에서 새로 작성했습니다. 원본 수집기의 실행 증빙을 대신하지 않습니다.
- API 접속, 인증정보, 추가 패키지 설치가 필요하지 않습니다.

Python 3.10 이상에서 저장소 폴더를 열고 실행합니다. Python 3.12에서 실행을 확인했습니다.

```powershell
python src/analyze_sample.py
```

예상 출력은 [실행 결과](docs/demo-output.md), 필드 설명은 [샘플 데이터 설명](docs/sample-data.md)을 참고하세요.

## 공개 범위

공개 대상은 프로젝트 설명, 일반적인 처리 흐름, 독립적으로 작성한 예제 코드와 합성 데이터입니다. API 인증 코드·키, 계좌정보, 원본 로그·시장 데이터, 종목 선별 조건, 연구 임계값과 핵심 매매전략, 기존 Git 이력은 포함하지 않습니다.

## 현재 한계와 다음 검증

- API 요청 제한과 누락 데이터 때문에 수집 시점과 실제 시장 시점에 차이가 생길 수 있습니다.
- 수집 코드의 개선이 실제 장중 수집률과 지연을 얼마나 바꾸었는지는 추가 관측이 필요합니다.
- 관측 이후 가격 변화율은 체결 가능한 매매 수익률과 다릅니다. 거래비용, 슬리피지, 주문 체결을 반영하지 않습니다.
- 연구 조건을 정한 데이터와 이후 검증 데이터를 구분하고, 관측 기간과 표본 수를 명시하는 검증을 이어갈 예정입니다.
- 이 공개본에는 검토를 마친 실제 성과 그래프나 실제 실행 화면을 아직 포함하지 않았습니다.
