# 데이터 수집 과정에서 다룬 문제

## 요청 지연과 작업 순서

원본 프로젝트는 후보 탐색과 후속 가격 수집을 함께 처리합니다. 후속 가격 조회가 길어지면 다음 관측이 늦어질 수 있어, 요청 간격과 작업 시간 예산을 관리하고 일부 작업을 다음 주기로 넘기는 코드가 있습니다.

공개 설명에서는 이런 문제와 접근 방법을 다룹니다. 내부 운영 설정값과 구체적인 종목 선별 조건은 제외했습니다. 개선 비율이나 실전 안정성은 이번 소스 검토만으로 검증하지 않았으므로 제시하지 않습니다.

## 누락된 관측을 구분하기

원본 분석 코드에는 유효한 관측을 선택하고, 중복 신호를 구분하고, 관측 이후 가격을 연구 데이터셋에 연결하는 처리가 있습니다. 관측이 없다는 이유만으로 가격 변화가 0이라고 처리하면 결과가 왜곡될 수 있습니다.

공개 예제는 이 중 일반적인 중복·가격 유효성 검사만 독립적으로 보여줍니다. 유효하지 않은 자료를 제외한 수와 계산에 사용한 수를 함께 출력합니다.

## 검증 상태

이번 공개본 정리에서는 원본 프로그램이나 API를 실행하지 않았습니다. 원본 테스트 파일의 존재는 확인했지만 테스트 통과 여부와 실제 장중 동작을 재검증한 것은 아닙니다. 공개 예제의 오프라인 실행만 별도로 확인했습니다.
