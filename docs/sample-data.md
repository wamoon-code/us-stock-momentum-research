# 합성 데이터 안내

이 파일은 실제 시장 자료에서 추출하지 않은 합성 데이터입니다. 종목 코드도 가상 이름입니다. 중복, 결측, 0원 기준가격 처리를 보여주기 위해 의도적으로 오류 사례를 넣었습니다.

| 필드 | 의미 |
|---|---|
| observation_id | 예제 관측 식별자. 중복이면 CSV에서 먼저 나온 행을 유지 |
| symbol | 가상 종목 이름 |
| observed_at | 설명용 UTC 관측 시각 |
| reference_price | 설명용 기준가격 |
| later_price | 설명용 후속가격. 실제 경과시간이나 체결을 뜻하지 않음 |

가격 변화율은 `(후속가격 / 기준가격 - 1) × 100`으로 계산합니다. 두 가격이 모두 유한한 양수일 때만 계산합니다. 빈 식별자, 중복 식별자, 잘못된 가격 순서로 구분하므로 제외 건수는 중복 집계되지 않습니다.

이 예제는 시간 정렬, 세션 경계, 시세 지연, 데이터 공급자의 수정 가격을 검증하지 않습니다. 실제 연구 파이프라인 전체를 재현하는 예제가 아닙니다.
