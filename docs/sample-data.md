# 합성 데이터 안내

이 저장소의 예제 데이터는 실제 시장 자료에서 추출하지 않은 합성 데이터입니다.

종목명, 가격, 시각, 관측 결과는 모두 데이터 처리 방식을 설명하기 위해 임의로 만든 값이며 실제 투자 성과나 실제 시장 관측값을 나타내지 않습니다.

현재 두 종류의 합성 데이터를 제공합니다.

- `synthetic_observations.csv`
- `synthetic_outcomes.csv`

---

## 1. synthetic_observations.csv

기본적인 데이터 유효성 검사와 중복 처리 방식을 보여주기 위한 예제입니다.

일부 행에는 중복 ID, 빈 가격, 0원 가격과 같은 오류 사례를 의도적으로 포함했습니다.

| 필드 | 의미 |
|---|---|
| observation_id | 예제 관측 식별자 |
| symbol | 가상 종목 이름 |
| observed_at | 설명용 관측 시각 |
| reference_price | 관측 시점의 기준가격 |
| later_price | 설명용 후속가격 |

동일한 `observation_id`가 반복될 경우 먼저 등장한 행을 사용하고 이후 행은 중복으로 구분합니다.

가격 변화율은 다음과 같이 계산합니다.

```text
(후속가격 / 기준가격 - 1) × 100
```

기준가격과 후속가격이 모두 유한한 양수일 때만 계산합니다.

빈 값이나 0 이하의 가격은 정상 가격으로 사용하지 않습니다.

이 예제는 다음 스크립트로 확인할 수 있습니다.

```powershell
python src/analyze_sample.py
```

## 2. synthetic_outcomes.csv

관측 이후 여러 시간 간격의 결과를 추적하는 연구 구조를 단순화한 합성 예제입니다.

단순히 후속 가격만 저장하는 것이 아니라, 해당 결과가 실제로 관측됐는지 또는 측정할 수 없었던 이유가 무엇인지 상태와 함께 기록합니다.

| 필드 | 의미 |
|---|---|
| signal_id | 합성 연구 신호 식별자 |
| symbol | 가상 종목 이름 |
| session | PRE 또는 REG 세션 |
| observed_at | 최초 연구 관측 시각 |
| horizon_min | 관측 이후 목표 시간 간격(분) |
| target_at | 측정하려는 목표 시각 |
| actual_observed_at | 실제 결과 데이터를 확보한 시각 |
| reference_price | 기준가격 |
| outcome_price | 후속 관측가격 |
| status | 결과의 관측 상태 |

### status

Outcome 예제에서는 다음 세 가지 상태를 사용합니다.

#### OBSERVED

목표 horizon의 결과 데이터를 정상적으로 확보한 경우입니다.

`reference_price`와 `outcome_price`를 이용해 가격 변화율을 계산합니다.

#### UNRESOLVED

해당 결과를 측정할 수 있는 조건이었지만 데이터를 확보하지 못한 경우를 나타냅니다.

예를 들어 API 요청 실패나 일시적인 데이터 누락 등이 있을 수 있습니다.

이 경우 가격 변화율을 0%로 처리하지 않습니다.

#### CENSORED

세션 종료 등으로 인해 해당 horizon을 구조적으로 측정할 수 없는 경우입니다.

예를 들어 정규장 종료 직전에 관측된 종목의 +30분 결과가 정규장 종료 이후에 위치한다면 해당 세션 안에서는 정상적으로 측정할 수 없습니다.

이 경우 역시 가격 변화율을 0%로 처리하지 않습니다.

## Outcome 분석 예제

`synthetic_outcomes.csv`는 다음 스크립트로 분석할 수 있습니다.

```powershell
python src/analyze_research_outcomes.py
```

예제 코드는 다음 항목을 확인합니다.

- 전체 Outcome 수
- 정상 관측 수
- UNRESOLVED 수
- CENSORED 수
- 중복 및 유효하지 않은 행
- horizon별 상태 분포
- 정상적으로 관측된 결과의 평균 가격 변화율
- 정상적으로 관측된 결과의 중앙값 가격 변화율

UNRESOLVED와 CENSORED는 가격 변화 계산에서 제외합니다.

이를 통해 실제로 가격이 움직이지 않은 경우와 데이터를 얻지 못한 경우를 서로 다른 상황으로 취급합니다.

## 실제 프로젝트와의 차이

공개 합성 데이터는 실제 연구 파이프라인의 개념을 설명하기 위한 단순화된 예제입니다.

다음 내용은 포함하지 않습니다.

- 실제 종목 및 시장 데이터
- 실제 API 응답
- 종목 선별 조건
- 연구 임계값
- 실제 전략 신호
- 실제 운영 로그
- 계좌 또는 주문 정보
- 실시간 WebSocket 원본 데이터

따라서 이 예제의 결과는 실제 투자 성과를 의미하지 않으며, 실제 연구 데이터셋 전체를 재현하는 것도 아닙니다.

공개 예제의 목적은 데이터 누락, 중복, 상태 구분과 같은 기본적인 연구 데이터 처리 방식을 확인할 수 있도록 하는 것입니다.
