# 합성 데이터 예제 실행 결과

공개 예제를 Python 3.12에서 실행해 확인한 출력입니다. 실제 시장 데이터나 실거래 성과가 아닙니다.

```text
SYNTHETIC DATA DEMO - not real market results
total: 8
duplicate: 1
invalid_id: 0
invalid_price: 2
valid: 5
mean_price_change_pct: +0.00
median_price_change_pct: +0.00
```

입력 8행 중 중복 1행과 가격이 유효하지 않은 2행을 제외하고 5행을 계산했습니다. 평균과 중앙값이 0%인 것은 합성 값의 구성에 따른 결과입니다. 투자 성과를 나타내지 않습니다.

README의 실행 명령으로 같은 결과를 재현할 수 있습니다. 터미널 화면을 캡처할 때는 이 합성 데이터 안내 문구가 보이도록 하고 개인 경로가 포함된 프롬프트는 제외합니다.
